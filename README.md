# No-Need-for-Quickbooks
A simple Excel-based accounting workbook that tracks journal entries, updates a trial balance, and generates basic financial statements using VBA.

## Included files
- `Core_Accounting.bas` — core VBA module for journal entry handling, trial balance updates, P&L generation, balance sheet generation, and ledger validation.

## Workbook structure
Create the following worksheets with these columns:

### `Journal`
- `Date`
- `Account`
- `Debit`
- `Credit`
- `Description`

### `ChartOfAccounts`
- `Account Name`
- `Balance`
- `Account Type` (Asset, Liability, Equity, Revenue, Expense)

### `P&L`
- Generated by VBA

### `BalanceSheet`
- Generated by VBA

## How to install the VBA module
1. Open the workbook in Excel.
2. Press `Alt + F11` to open the VBA editor.
3. Right-click `VBAProject`, choose `Import File...`, and select `Core_Accounting.bas`.
4. Save the workbook as a macro-enabled workbook (`.xlsm`).

## How to use
- `AddJournalEntry(accountName, debit, credit, description)` — adds a new row to the `Journal` sheet.
- `UpdateTrialBalance()` — updates `ChartOfAccounts` balances from journal activity.
- `UpdateFinancialStatements()` — rebuilds the `P&L` and `BalanceSheet` sheets.
- `RefreshAccounting()` — runs both trial balance and financial statements updates.
- `IsBalanced()` — returns `True` when total journal debits equal total journal credits.

## Recommended workflow
1. Populate `ChartOfAccounts` with account names and types.
2. Enter journal entries using `Journal`, or call `AddJournalEntry` from VBA.
3. Run `RefreshAccounting()` to update the trial balance and financial statements.
4. Verify the ledger with `IsBalanced()`.

## Notes
- The module includes validation for journal entries and worksheet existence checks.
- The financial statement output is automatically formatted for readability.
